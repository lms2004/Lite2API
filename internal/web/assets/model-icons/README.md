# Official channel and model icons

These files are vendor-provided assets embedded unchanged into the canonical
admin page. They were retrieved on 2026-08-31 and are used only next to the
corresponding channel or model name.

- `openai.svg`: OpenAI Developers favicon, from
  <https://developers.openai.com/favicon.svg>.
- `claude.svg`: `ClaudeIcon-Rounded.svg` from Anthropic's official press kit,
  downloaded via <https://www.anthropic.com/press-kit>.
- `gemini-api-logo.svg`: Gemini API lockup from
  <https://ai.google.dev/_static/googledevai/images/gemini-api-logo.svg>. The
  UI clips the unchanged lockup to its left-hand Gemini symbol at icon sizes.
- `antigravity.png`: full-color Antigravity icon from
  <https://antigravity.google/assets/image/brand/antigravity-icon__full-color.png>.
- OpenAI model PNGs: official model artwork from the OpenAI Developers model
  catalog under `https://developers.openai.com/images/api/models/icons/`:
  `gpt-5.6-sol.png`, `gpt-5.6-terra.png`, `gpt-5.6-luna.png`, `gpt-5.5.png`,
  `gpt-5.4.png`, `gpt-5.4-mini.png`, `gpt-5.3-codex.png`, `gpt-image-2.png`,
  and `gpt-oss-120b.png`.

Do not recolor, redraw, or pass these assets through image generation. Follow
each vendor's current trademark and brand-usage terms when redistributing.
