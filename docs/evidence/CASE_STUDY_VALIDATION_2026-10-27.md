## 2. 当前已有回归测试

执行非缓存竞态测试：

```bash
GOTOOLCHAIN=local GOCACHE=/tmp/lite2api-case-study-go-cache \
  go test -race ./... -count=1 -json
node --test internal/web/app-core.test.js internal/web/app-runtime.test.js
```

| 测试范围 | 结果 |
|---|---|
| `internal/config` | PASS，1.154 秒 |
| `internal/gateway` | PASS，21.566 秒 |
| `internal/web` | PASS，3.726 秒 |
| `cmd/lite2api` | 无测试文件 |
| Go 测试事件 | 243 PASS、0 FAIL |
| Node 前端逻辑测试文件 | 2 PASS、0 FAIL |

上述用例包含以下正文所依赖的行为：

- 操作类型筛选、逻辑模型到真实渠道映射和显式目标顺序。
- 静态操作不兼容在 100 毫秒内退出，不等待所传入的 1 秒容量等待预算。
- 明确拒绝后主目标与备用目标各收到 1 次请求；不确定提交后主目标收到 1 次、备用目标收到 0 次。
- 受信适配器未提交证明允许切换，客户端同名请求头被剥离。
- Key 并发或请求体内存预算拒绝时，请求体读取为 0。
- 200 响应头之后的流中断计为失败；低流量路由的失败证据不会随最近请求环淘汰而消失。
- 热加载与并发容量、配置更新、Key 管理的相关回归。

第一次受限环境执行在创建本地 IPv6 `httptest` 监听时被沙箱拒绝；取得本地测试执行权限后重跑，全套通过。测试只使用已有测试与隔离夹具，不连接生产实例。
